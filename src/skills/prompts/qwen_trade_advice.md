## 任务要求
请综合分析以上信息，给出你的操作建议。你必须按以下 JSON 格式输出：

```json
{{
    "action": "持有" 或 "买入" 或 "卖出" 或 "建仓",
    "reason": "简要说明操作理由（2-3句话）",
    "analysis_summary": "技术面概要（1句话）"
}}
```

## 决策参考
- 若用户无持仓，请根据技术面判断是否为合适的建仓时机
- 若用户有持仓且亏损超过10%，需谨慎考虑是否止损
- 若用户偏好保守，不建议追高买入
- 若技术指标明显超买，建议观望不建仓
- 若技术指标超卖且有反弹信号，可考虑建仓或加仓

只输出 JSON，不要其他内容。
